# Contributing

Issues and pull requests are welcome. Describe the console model, firmware,
application version, exact input and reproduction steps. A minimal mathematical
example is particularly useful for numerical bugs.

Run `make check` before proposing code changes. Keep PT and EN labels consistent,
preserve the installation layout, avoid committing state/logs and document
numerical limits. New hardware behavior needs explicit on-console testing;
passing desktop tests is not proof of firmware compatibility.

Code and documentation contributions are intended to be distributed under the
project's MIT license. Preserve third-party notices.
