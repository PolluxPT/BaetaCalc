# Changelog

## 2.5.1 — 2026-10-22

- Start in English on first launch or when the language preference is missing,
  empty or invalid.
- Preserve explicitly saved Portuguese and English preferences across updates.
- Accept language files with LF, CRLF or no trailing newline.
- Update language regression tests, manuals and versioned release packaging.

## 2.5.0 — first public package

- European Portuguese / English interface and separate calculator, functions
  and equation environments.
- Normal/scientific keyboards, cursor editing and consistent navigation.
- Exact supported fractions and real radicals, simplification, rationalization
  and exact Ans metadata for the current session.
- Y/X graphs, tables, TRACE, panning, zoom and shading.
- Polynomial and interval roots, two/three-variable linear systems and
  two-variable nonlinear systems.
- Exit confirmation, mathematical reset and firmware-dependent POWER handling.
- Public source layout, tests, manuals and license notices.

The application identifies this version as 2.5. GitHub's tag is v2.5.0.
POWER suspend/resume still requires hardware validation.
